# Compiling

Requires [devkitPro](https://devkitpro.org/wiki/Getting_Started) with the `3ds-dev`
package and `libvorbisidec` (portlibs).

Set the toolchain environment and build:

```sh
export DEVKITPRO=/opt/devkitpro
export DEVKITARM=$DEVKITPRO/devkitARM
export PATH=$PATH:$DEVKITPRO/tools/bin:$DEVKITARM/bin

make
Output: mayro.3dsx (plus mayro.elf and mayro.smdh).
Clean:
make clean
```
